## Preview locally
Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to Netlify
1. Extract this ZIP.
2. Sign in to Netlify.
3. Choose **Add new site → Deploy manually** (or drag-and-drop deploy).
4. Drag the extracted project folder into the deploy area.

For a Git-based deployment, push the files to GitHub, import the repository in Netlify, leave the build command empty, and set the publish directory to `.`.
